# Character avatars

Put one image per character here, named after the character's slug:

```text
characters/avatars/elena.jpg      (.jpg, .jpeg, .png or .webp)
```

The Telegram gallery shows it above the character's name. Without a file here
the bot falls back to the character's `avatar_url` (must be an `https://`
link Telegram can download), and without either it shows a text card.

Tips: square or portrait images work best; keep them under 10 MB.
